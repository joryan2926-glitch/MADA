# Charte Éditoriale MADA

## Mouvement pour l'Avenir, le Développement et l'Autodétermination

**Version :** 0.1 - Ligne éditoriale officielle  
**Statut :** Document de référence interne  
**Usage :** site officiel, communiqués, réseaux sociaux, dossiers, tribunes, podcasts, vidéos, réponses citoyennes, campagne CTM 2028.

---

## 1. Rôle de la charte éditoriale

La charte éditoriale MADA fixe les règles de parole, de publication et de vérification du mouvement.

Elle doit permettre à MADA de parler avec sérieux, clarté et cohérence, tout en restant proche des Martiniquais. Elle protège le mouvement contre l'improvisation, les contradictions publiques, les attaques inutiles, les promesses floues et les erreurs de communication.

MADA doit être reconnu pour une parole responsable : une parole qui explique, qui documente, qui propose et qui rend compte.

---

## 2. Mission éditoriale

La mission éditoriale de MADA est de :

- rendre compréhensibles les réalités de la Martinique ;
- expliquer qui décide, qui finance et qui est responsable ;
- documenter les crises, les blocages et les possibilités d'action ;
- présenter des solutions crédibles ;
- valoriser les communes, les talents, les producteurs, les associations et les initiatives locales ;
- créer une culture politique de transparence ;
- préparer les citoyens à participer à la construction du territoire.

La communication MADA ne doit pas seulement convaincre. Elle doit élever le niveau de compréhension collective.

---

## 3. Positionnement de parole

MADA parle comme un mouvement politique martiniquais responsable, enraciné dans le territoire et tourné vers l'action.

Le ton doit être :

- institutionnel sans être froid ;
- ferme sans être agressif ;
- populaire sans être simpliste ;
- pédagogique sans être condescendant ;
- ambitieux sans être irréaliste ;
- local sans être fermé au monde.

---

## 4. Les règles d'or

Toute publication MADA doit respecter sept règles :

1. **Dire vrai** : ne pas masquer les difficultés.
2. **Expliquer simplement** : rendre le sujet compréhensible.
3. **Identifier les responsabilités** : ne pas accuser sans précision.
4. **Proposer une solution** : ne pas rester dans le constat permanent.
5. **Rester digne** : ne pas humilier, caricaturer ou insulter.
6. **Sourcer les chiffres** : ne pas inventer de données.
7. **Rendre compte** : assumer les engagements et les résultats.

---

## 5. Niveaux de parole

## 5.1 Parole officielle

La parole officielle engage le mouvement. Elle concerne :

- les communiqués ;
- les positions politiques ;
- les annonces de programme ;
- les décisions internes importantes ;
- les réponses à la presse ;
- les prises de position de campagne.

Elle doit être validée par la direction ou par une personne explicitement habilitée.

## 5.2 Parole thématique

La parole thématique concerne les dossiers produits par les équipes de travail : économie, santé, eau, agriculture, jeunesse, sécurité, logement, environnement, culture, institutions.

Elle doit être documentée, prudente et alignée avec le Référentiel Fondateur.

## 5.3 Parole militante

La parole militante permet de faire vivre le mouvement sur le terrain et les réseaux. Elle doit rester libre dans l'énergie, mais alignée dans les valeurs.

Un militant MADA doit éviter :

- les insultes ;
- les accusations non vérifiées ;
- les attaques personnelles ;
- les promesses qu'il ne peut pas garantir ;
- les contradictions avec les positions officielles.

---

## 6. Formats éditoriaux

## 6.1 Communiqué officiel

Objectif : annoncer une position ou réagir à un événement important.

Structure recommandée :

1. titre clair ;
2. contexte ;
3. position de MADA ;
4. proposition ou demande ;
5. engagement de suivi ;
6. contact officiel.

Le communiqué doit être court, précis et digne.

## 6.2 Dossier pédagogique

Objectif : expliquer un sujet de fond.

Structure recommandée :

1. pourquoi ce sujet compte ;
2. état des lieux ;
3. qui est responsable ;
4. ce qui bloque ;
5. ce que MADA propose ;
6. financements possibles ;
7. indicateurs de réussite.

## 6.3 Article d'actualité

Objectif : informer les citoyens sur l'activité du mouvement ou un sujet territorial.

Structure recommandée :

- fait principal ;
- contexte ;
- conséquences pour les Martiniquais ;
- action ou position MADA ;
- lien vers une rubrique plus complète si nécessaire.

## 6.4 Fiche programme

Objectif : rendre une proposition claire et crédible.

Chaque fiche doit préciser :

- problème ;
- public concerné ;
- proposition ;
- rôle de la CTM ;
- partenaires ;
- budget estimatif ou ordre de grandeur ;
- financement possible ;
- calendrier ;
- indicateurs.

## 6.5 Publication réseaux sociaux

Objectif : transmettre rapidement une idée, une action ou une information.

Règles :

- une idée principale par publication ;
- texte court ;
- visuel lisible ;
- source lorsqu'un chiffre est cité ;
- appel à l'action clair ;
- pas de polémique gratuite.

## 6.6 Podcast et vidéo

Objectif : expliquer, écouter, débattre et documenter.

Structure recommandée :

1. introduction courte ;
2. présentation du sujet ;
3. faits et contexte ;
4. témoignage ou expertise ;
5. solutions possibles ;
6. conclusion utile ;
7. invitation à contribuer.

---

## 7. Ligne éditoriale de MADA - Les Voix de la Martinique

**MADA - Les Voix de la Martinique** doit être un média citoyen de compréhension du territoire.

Sa promesse éditoriale :

**Comprendre aujourd'hui. Construire demain.**

Le média doit traiter :

- les réalités sociales ;
- les communes ;
- les crises depuis 2009 ;
- l'économie martiniquaise ;
- les institutions ;
- les responsabilités publiques ;
- les solutions possibles ;
- les talents ;
- les initiatives locales ;
- la culture ;
- la diaspora ;
- les grands projets.

Il doit donner la parole sans perdre la rigueur.

---

## 8. Vérification des faits

MADA doit distinguer clairement :

- un fait ;
- une donnée ;
- une estimation ;
- une analyse ;
- une opinion ;
- une proposition politique.

## 8.1 Sources recommandées

Lorsque des chiffres sont utilisés, privilégier :

- INSEE ;
- IEDOM ;
- Cour des comptes ;
- Chambre régionale des comptes ;
- CTM ;
- Préfecture ;
- ministères ;
- agences publiques ;
- Union Européenne ;
- rapports parlementaires ;
- observatoires publics ;
- documents budgétaires officiels.

## 8.2 Règle de prudence

Lorsqu'une donnée est incertaine, ancienne ou incomplète, MADA doit l'indiquer clairement. Il vaut mieux dire :

**Les données disponibles indiquent...**

plutôt que d'affirmer sans nuance.

---

## 9. Droit de réponse et correction

MADA doit accepter la correction lorsqu'une erreur est identifiée.

Procédure recommandée :

1. signalement reçu ;
2. vérification interne ;
3. correction si nécessaire ;
4. mention de la correction lorsque le sujet est public ;
5. archivage de la modification.

Corriger une erreur n'est pas une faiblesse. C'est une preuve de sérieux.

---

## 10. Réponses aux attaques

MADA doit répondre avec calme et précision.

Règles :

- ne pas répondre à toutes les provocations ;
- répondre aux sujets qui touchent l'intérêt public ;
- corriger les fausses informations ;
- éviter les attaques personnelles ;
- revenir aux faits, au programme et aux responsabilités ;
- garder une posture digne.

Formule type :

**MADA répond par les faits, par la méthode et par le travail.**

---

## 11. Protection des personnes

MADA doit être particulièrement prudent lorsqu'il traite de sujets sensibles :

- enfance ;
- violences faites aux femmes ;
- pédocriminalité ;
- harcèlement scolaire ;
- santé mentale ;
- pauvreté ;
- personnes sans domicile ;
- victimes de catastrophes ;
- familles en difficulté.

Règles :

- ne jamais exposer une victime sans accord ;
- protéger les mineurs ;
- éviter les détails inutiles ;
- orienter vers les dispositifs compétents ;
- ne pas instrumentaliser la souffrance.

---

## 12. Communication de crise

En période de crise, MADA doit :

1. vérifier les faits ;
2. éviter la panique ;
3. expliquer les responsabilités ;
4. relayer les consignes utiles ;
5. proposer une solution ou une demande claire ;
6. rester disponible pour les citoyens.

Sujets concernés : eau, santé, sargasses, cyclone, transport, sécurité, crise sociale, vie chère, catastrophe naturelle, crise institutionnelle.

---

## 13. Relation avec la presse

Les relations presse doivent être centralisées.

Toute réponse à un média doit préciser :

- qui parle ;
- au nom de quelle responsabilité ;
- sur quel sujet ;
- avec quelle position validée.

MADA doit préparer :

- communiqués ;
- dossiers de presse ;
- biographies officielles ;
- photos officielles ;
- argumentaires ;
- contacts presse.

---

## 14. Style d'écriture

## 14.1 À privilégier

- phrases courtes ;
- vocabulaire clair ;
- ton direct ;
- paragraphes aérés ;
- exemples concrets ;
- chiffres sourcés ;
- formulation institutionnelle.

## 14.2 À éviter

- jargon administratif inutile ;
- slogans vides ;
- textes trop longs sans structure ;
- promesses absolues ;
- accusation sans preuve ;
- moquerie ;
- dramatisation permanente.

---

## 15. Lexique politique MADA

Expressions à faire vivre :

- construire la Martinique de demain ;
- produire ici, décider ici, réussir ici ;
- transparence budgétaire ;
- autodétermination responsable ;
- retour des talents ;
- justice territoriale ;
- économie productive ;
- communes écoutées ;
- Martinique 2040 ;
- action, responsabilité, résultats.

Expressions à utiliser avec prudence :

- autonomie ;
- souveraineté ;
- rupture ;
- crise ;
- scandale ;
- responsable ;
- faute ;
- promesse.

Ces mots doivent être définis, contextualisés et utilisés avec sérieux.

---

## 16. Validation avant publication

Avant publication d'un contenu important, vérifier :

- titre clair ;
- message principal identifiable ;
- cohérence avec le Référentiel Fondateur ;
- absence de chiffre non sourcé ;
- ton digne ;
- respect des personnes ;
- correction des accents ;
- lisibilité mobile ;
- appel à l'action utile ;
- validation par la bonne personne.

---

# Conclusion

La charte éditoriale MADA doit permettre au mouvement de construire une parole durable, sérieuse et respectée.

MADA ne doit pas parler pour occuper l'espace. MADA doit parler pour éclairer, organiser, proposer et rendre compte.

**Une parole claire crée la confiance. Une parole vérifiée crée la crédibilité. Une parole utile prépare l'action.**
