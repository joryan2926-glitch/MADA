# Charte Graphique MADA

## Mouvement pour l'Avenir, le Développement et l'Autodétermination

**Version :** 0.1 - Socle visuel officiel  
**Statut :** Document de référence interne  
**Usage :** site internet, réseaux sociaux, communiqués, affiches, documents PDF, campagne terrain, média MADA - Les Voix de la Martinique.

---

## 1. Rôle de la charte

La charte graphique MADA fixe les règles visuelles du mouvement afin que chaque support donne la même impression : sérieux, crédibilité, modernité, proximité et fierté martiniquaise.

L'objectif n'est pas seulement de faire beau. L'objectif est de rendre MADA immédiatement reconnaissable, institutionnel et cohérent, que le citoyen voie le mouvement sur un site, une affiche, une vidéo, un podcast, un tract, un document public ou une publication sociale.

---

## 2. Principes visuels

L'identité MADA doit transmettre :

- la responsabilité publique ;
- la dignité martiniquaise ;
- le développement économique ;
- l'enracinement territorial ;
- l'ouverture caribéenne ;
- la transparence ;
- l'action concrète.

Le style général doit rester institutionnel, premium, lisible et moderne. MADA ne doit pas ressembler à un template générique ni à une communication improvisée.

---

## 3. Logo MADA

## 3.1 Logo principal

Le logo MADA validé repose sur :

- la forme de la Martinique ;
- les couleurs vert, jaune doré, marron et blanc ;
- une évocation du relief, de la terre, du palmier et du mouvement ;
- le nom MADA en lettres fortes ;
- le nom complet du mouvement.

Le logo principal doit être utilisé sur :

- le site officiel ;
- les documents institutionnels ;
- les communiqués ;
- les supports de campagne ;
- les visuels de présentation ;
- les pages d'ouverture ;
- les vidéos et podcasts.

## 3.2 Règles d'usage

Le logo doit toujours rester lisible. Il ne doit pas être déformé, compressé, recoloré arbitrairement ou placé sur un fond qui empêche sa lecture.

À respecter :

- conserver les proportions du logo ;
- garder une zone de respiration autour du logo ;
- privilégier les fonds vert profond ou blancs selon la version utilisée ;
- éviter les effets supplémentaires non validés ;
- ne pas remplacer la carte de Martinique par une autre forme.

## 3.3 Zone de protection

Autour du logo, laisser une marge minimale équivalente à la hauteur de la lettre **M** de MADA. Aucun texte, bouton, icône ou bord de document ne doit entrer dans cette zone.

## 3.4 Tailles minimales

- Site desktop : logo lisible dans le header sans dominer le menu.
- Mobile : privilégier une version compacte si nécessaire.
- Documents imprimés : ne jamais utiliser une taille qui rend le nom complet illisible.
- Réseaux sociaux : utiliser une version simplifiée ou centrée lorsque le format est carré.

---

## 4. Couleurs officielles

## 4.1 Palette principale

| Couleur | Usage | Valeur symbolique |
| --- | --- | --- |
| Vert profond | fonds principaux, header, footer, overlays | sérieux, territoire, enracinement |
| Jaune doré | boutons, accents, chiffres, soulignements | énergie, ambition, réussite |
| Marron terre | détails, profondeur, identité locale | terre, travail, transmission |
| Blanc | textes principaux sur fond sombre | clarté, vérité, lisibilité |
| Noir profond | overlays, contraste, sections premium | autorité, sobriété, institution |

## 4.2 Règles d'association

Le vert profond doit rester la couleur dominante. Le doré doit servir d'accent, pas devenir un fond permanent. Le blanc doit garantir la lisibilité. Le marron doit être utilisé avec retenue pour rappeler la terre et la profondeur historique.

MADA doit éviter les palettes trop claires, trop criardes ou trop éloignées de l'identité validée.

## 4.3 Drapeau politique de référence

Le drapeau rouge, vert et noir doit être utilisé comme référence politique et territoriale visuelle :

- triangle rouge à gauche ;
- bande verte en haut ;
- bande noire en bas.

L'ancien drapeau bleu/blanc ne doit pas être utilisé dans l'identité MADA.

---

## 5. Typographie

## 5.1 Style typographique

La typographie MADA doit être :

- puissante sans être agressive ;
- institutionnelle sans être froide ;
- moderne sans être fantaisiste ;
- lisible sur mobile, tablette et desktop.

Les titres doivent donner une impression de décision et de sérieux. Les textes longs doivent rester confortables à lire.

## 5.2 Hiérarchie

- **H1** : titre principal de page, court, fort, lisible.
- **H2** : grande section structurante.
- **H3** : sous-partie ou carte importante.
- **Texte courant** : phrases claires, paragraphes courts.
- **Chiffres clés** : grands mais contrôlés, en doré ou vert selon le fond.

## 5.3 Règles de lisibilité

Éviter les titres trop massifs qui prennent tout l'écran. Les titres doivent rester puissants mais maîtrisés, surtout sur mobile.

Les textes blancs doivent toujours être placés sur un fond suffisamment sombre. Les blocs clairs doivent utiliser du texte foncé.

---

## 6. Photographie et images

## 6.1 Direction photographique

Les images MADA doivent montrer une Martinique réelle : paysages, communes, agriculture, mer, montagnes, centres-bourgs, jeunesse, patrimoine, travail, sport, santé, culture, infrastructures et vie locale.

Il faut éviter les images génériques qui pourraient représenter n'importe quel territoire.

## 6.2 Traitement visuel

Sur le site, les photos doivent être harmonisées par :

- overlay vert profond ;
- dégradé noir ;
- contraste fort ;
- lisibilité du texte ;
- cohérence avec les couleurs MADA.

## 6.3 Images à privilégier

- Vue aérienne de la Martinique.
- Montagne Pelée, littoral, mornes, rivières, mangroves.
- Centres-bourgs, mairies, marchés, places de village.
- Agriculture locale, pêche, transformation alimentaire.
- Jeunesse, formation, sport, culture, carnaval, musique.
- Infrastructures, eau, énergie, santé, mobilité.

## 6.4 Images à éviter

- Photos trop génériques de banque d'images.
- Images sombres sans sujet identifiable.
- Visuels qui caricaturent la Martinique.
- Images politiques agressives.
- Images qui pourraient prêter à confusion avec une institution publique officielle.

---

## 7. Iconographie

Les icônes doivent être simples, lisibles et cohérentes. Elles servent à guider le citoyen, pas à décorer inutilement.

Usages recommandés :

- économie : graphique, entreprise, monnaie, production ;
- santé : croix médicale, coeur, maison de santé ;
- eau : goutte, réseau, réservoir ;
- agriculture : feuille, panier, champ ;
- jeunesse : diplôme, groupe, sport ;
- transparence : oeil, document, balance ;
- territoire : carte, repère, commune ;
- action : flèche, main, cible.

---

## 8. Mise en page

## 8.1 Style général

La mise en page MADA doit rester claire, dense mais respirante. Les pages doivent être organisées comme des documents publics modernes : introduction, constats, propositions, méthode, chiffres, calendrier, appel à l'action.

## 8.2 Cartes et blocs

Les cartes doivent servir à organiser l'information. Elles doivent rester sobres, alignées, responsive et lisibles.

Règles :

- éviter les cartes trop hautes sans raison ;
- éviter les textes trop petits ;
- garder des marges régulières ;
- éviter les effets décoratifs excessifs ;
- utiliser le doré pour hiérarchiser, pas pour surcharger.

## 8.3 Tableaux

Les tableaux doivent être utilisés lorsqu'ils clarifient les responsabilités, les budgets, les indicateurs ou les calendriers.

Ils doivent être :

- lisibles sur mobile ;
- non débordants ;
- avec contraste clair ;
- accompagnés d'une explication simple.

---

## 9. Supports numériques

## 9.1 Site officiel

Le site officiel doit rester la référence centrale. Toute page doit permettre au citoyen de comprendre rapidement :

- qui parle ;
- quel problème est traité ;
- ce que propose MADA ;
- comment agir ou contribuer.

## 9.2 Réseaux sociaux

Les visuels sociaux doivent conserver :

- logo MADA ;
- couleurs officielles ;
- titre court ;
- phrase claire ;
- source ou contexte lorsqu'un chiffre est utilisé ;
- appel à l'action discret mais visible.

## 9.3 Vidéo et podcast

Pour MADA - Les Voix de la Martinique, l'identité doit reprendre :

- vert profond ;
- doré ;
- micro ou onde sonore ;
- carte de Martinique ;
- slogan média : **Comprendre aujourd'hui. Construire demain.**

---

## 10. Supports imprimés

Les documents imprimés doivent être sobres et institutionnels :

- logo clair ;
- titres lisibles ;
- texte structuré ;
- encadrés pour les chiffres ;
- pas de surcharge graphique ;
- mentions légales lorsque nécessaire ;
- contact officiel MADA.

Supports concernés :

- tracts ;
- livrets programme ;
- affiches ;
- communiqués ;
- dossiers de presse ;
- fiches communales ;
- documents de formation.

---

## 12. Règles de cohérence

Chaque support MADA doit respecter quatre exigences :

1. **Reconnaissance** : on doit identifier MADA rapidement.
2. **Lisibilité** : le message doit être compris sans effort.
3. **Crédibilité** : le style doit inspirer confiance.
4. **Utilité** : le support doit informer, mobiliser ou expliquer.

---

## 13. À ne pas faire

MADA doit éviter :

- les visuels trop chargés ;
- les typographies fantaisistes ;
- les couleurs hors identité ;
- les promesses visuelles spectaculaires mais vides ;
- les montages qui brouillent le message ;
- les images non martiniquaises pour parler du territoire ;
- les tableaux illisibles ;
- les textes blancs sur fond clair ;
- les titres trop grands qui écrasent le contenu.

---

## 14. Contrôle qualité avant publication

Avant publication d'un support MADA, vérifier :

- logo présent et lisible ;
- couleurs conformes ;
- texte relu ;
- accents corrects ;
- contraste suffisant ;
- image cohérente avec le sujet ;
- source indiquée lorsqu'un chiffre est cité ;
- format adapté au support ;
- version mobile vérifiée pour les pages web ;
- absence de confusion avec une institution officielle existante.

---

# Conclusion

La charte graphique MADA doit donner au mouvement une image stable, forte et sérieuse. Elle doit faire comprendre que MADA n'est pas une communication improvisée, mais une organisation politique qui veut construire dans la durée.

**Une identité claire crée de la confiance. Une identité cohérente crée de la mémoire. Une identité utile sert l'action.**
