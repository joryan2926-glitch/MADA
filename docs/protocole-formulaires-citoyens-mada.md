# Protocole de Traitement des Formulaires Citoyens MADA

## Mouvement pour l'Avenir, le Développement et l'Autodétermination

**Version :** 0.1 - Gestion des demandes citoyennes  
**Statut :** Document opérationnel interne  
**Usage :** administrateurs du site, équipe numérique, coordination territoriale, responsables adhésion, bénévolat, programme, dons, contacts et relais communaux.

---

## 1. Pourquoi ce protocole existe

Le site MADA reçoit des informations citoyennes importantes : adhésions, demandes de bénévolat, contacts, inscriptions newsletter, contributions au programme, relais communaux, intentions de don, idées liées aux projets et signalements territoriaux.

Chaque formulaire représente une personne qui fait une démarche vers le mouvement. Cette démarche doit être traitée avec sérieux, confidentialité et méthode.

Ce protocole fixe les règles internes pour recevoir, classer, répondre, suivre et protéger les données transmises à MADA.

---

## 2. Principes généraux

MADA doit appliquer sept principes :

1. **Respect** : chaque personne reçoit une attention digne.
2. **Confidentialité** : les données ne sont pas diffusées inutilement.
3. **Utilité** : chaque demande doit être orientée vers la bonne équipe.
4. **Traçabilité** : chaque action importante doit pouvoir être suivie.
5. **Réactivité** : aucune demande ne doit rester oubliée.
6. **Sécurité** : seuls les administrateurs autorisés accèdent aux données.
7. **Sobriété** : ne collecter que les informations nécessaires.

## 4. Chaîne de traitement

Chaque soumission doit suivre une chaîne simple :

1. réception dans la base sécurisée ;
2. notification interne si disponible ;
3. qualification de la demande ;
4. affectation à une équipe ;
5. réponse ou prise de contact ;
6. suivi de l'action ;
7. archivage.

Aucune donnée citoyenne ne doit être laissée sans responsable identifié.

---

## 5. Délais internes recommandés

| Type de demande | Délai cible |
| --- | --- |
| Adhésion | accusé de réception immédiat si possible, traitement sous 72 h |
| Bénévolat | premier contact sous 5 jours ouvrés |
| Contact général | réponse sous 5 jours ouvrés |
| Relais communal | qualification sous 7 jours ouvrés |
| Contribution programme | classement sous 10 jours ouvrés |
| Intention de don | contact ou orientation sous 72 h |
| Signalement sensible | remontée prioritaire sous 24 à 48 h |
| Newsletter | inscription automatique ou validation immédiate |

Ces délais sont des objectifs internes. Ils devront être ajustés selon la capacité réelle de l'équipe.

## 7. Gestion des adhésions

Une demande d'adhésion doit être traitée avec attention.

Étapes recommandées :

1. vérifier que les informations essentielles sont présentes ;
2. envoyer ou préparer un message d'accueil ;
3. rattacher la personne à une commune ou un bassin ;
4. proposer une première action simple ;
5. indiquer les documents de référence ;
6. inscrire dans le suivi adhérent.

Documents utiles à transmettre :

- Référentiel Fondateur ;
- Manuel du Bénévole ;
- Charte Éditoriale ;
- lien vers le site officiel ;
- contact territorial.

---

## 8. Gestion du bénévolat

Une personne qui propose son aide doit être orientée selon :

- sa commune ;
- ses compétences ;
- son temps disponible ;
- ses centres d'intérêt ;
- son expérience ;
- son niveau d'engagement souhaité.

Types de missions possibles :

- terrain ;
- logistique ;
- communication ;
- rédaction ;
- photographie ;
- vidéo ;
- numérique ;
- expertise programme ;
- organisation d'événements ;
- relation diaspora.

---

## 9. Gestion des contributions programme

Chaque contribution doit être lue, classée et orientée.

Une contribution peut devenir :

- une idée à étudier ;
- une mesure à intégrer ;
- un signalement territorial ;
- une question à clarifier ;
- une proposition hors compétence CTM ;
- une contribution à archiver.

MADA doit éviter deux erreurs : ignorer les idées citoyennes ou promettre de toutes les appliquer.

La bonne méthode : remercier, classer, analyser, puis intégrer seulement ce qui est cohérent, réaliste et finançable.

---

## 10. Gestion des relais communaux

Une candidature relais communal doit être traitée avec prudence.

Avant validation, vérifier :

- motivation ;
- commune concernée ;
- disponibilité ;
- capacité à respecter la ligne MADA ;
- posture citoyenne ;
- absence de conflit évident avec les valeurs du mouvement ;
- besoin de formation.

Un relais communal ne doit pas être nommé trop vite. Il représente localement le sérieux du mouvement.

---

## 11. Gestion des intentions de don

Les intentions de don doivent être traitées avec rigueur.

Règles :

- respecter le cadre légal du financement politique et associatif applicable ;
- ne jamais accepter de contribution hors procédure validée ;
- vérifier les informations nécessaires ;
- orienter vers le responsable financier ;
- conserver une traçabilité claire ;
- ne jamais promettre d'avantage en échange d'un don.

Phrase repère :

**Un soutien financier doit renforcer l'action collective, jamais acheter une influence.**

---

## 12. Gestion des contacts sensibles

Sont considérés comme sensibles :

- violences ;
- mineurs ;
- santé ;
- détresse sociale ;
- situation juridique ;
- menace ;
- harcèlement ;
- données personnelles très précises ;
- accusation nominative.

Ces demandes doivent être remontées à une personne responsable et ne doivent pas être diffusées dans des groupes larges.

MADA peut écouter et orienter, mais ne doit pas se substituer aux autorités compétentes, aux services sociaux, aux professionnels de santé ou à la justice.

---

## 13. Accès administrateur

L'accès aux données doit être limité aux personnes autorisées.

Chaque administrateur doit :

- utiliser un compte personnel ;
- ne pas partager ses identifiants ;
- se déconnecter après usage ;
- éviter les accès depuis un appareil non sécurisé ;
- signaler toute anomalie ;
- respecter la confidentialité.

Les accès doivent être revus régulièrement.

---

## 14. Export et partage des données

Aucun export de données ne doit être réalisé sans raison claire.

Avant tout export, vérifier :

- objectif ;
- destinataire ;
- données nécessaires ;
- durée de conservation ;
- niveau de confidentialité ;
- autorisation interne.

Les fichiers exportés doivent être protégés et supprimés lorsqu'ils ne sont plus nécessaires.

## 15. Messages types

## 15.1 Accusé de réception général

Bonjour,

Merci pour votre message et pour l'intérêt porté à MADA. Votre demande a bien été reçue. Elle sera orientée vers l'équipe concernée afin d'être étudiée avec sérieux.

MADA - Construire la Martinique de demain.

## 15.2 Réponse bénévolat

Bonjour,

Merci pour votre volonté d'agir avec MADA. Nous allons examiner votre disponibilité, votre commune et vos compétences afin de vous proposer une mission utile au mouvement et au territoire.

## 15.3 Réponse contribution programme

Bonjour,

Merci pour votre contribution au programme MADA. Votre proposition sera classée par thème et étudiée par l'équipe concernée. Toutes les idées ne peuvent pas être retenues telles quelles, mais chaque contribution utile aide à construire une vision plus proche du terrain.

## 15.4 Réponse relais communal

Bonjour,

Merci pour votre volonté de devenir relais communal MADA. Ce rôle demande sérieux, disponibilité et respect de la ligne du mouvement. Nous reviendrons vers vous pour mieux comprendre votre motivation et votre commune.

---

## 16. Indicateurs de suivi

MADA doit suivre :

- nombre de formulaires reçus ;
- délai moyen de réponse ;
- demandes par commune ;
- demandes par thème ;
- adhésions confirmées ;
- bénévoles actifs ;
- relais communaux qualifiés ;
- contributions intégrées au programme ;
- demandes sensibles traitées ;
- taux de demandes sans réponse.

---

## 17. Audit mensuel

Chaque mois, l'équipe responsable doit vérifier :

- demandes non traitées ;
- doublons ;
- erreurs de classification ;
- délais dépassés ;
- besoin de nouveaux responsables ;
- thèmes émergents ;
- communes les plus actives ;
- problèmes techniques.

Ce suivi doit nourrir le tableau de bord interne MADA.

---

# Conclusion

Un formulaire n'est pas une simple ligne dans une base de données. C'est une démarche citoyenne.

MADA doit traiter chaque demande avec méthode, confidentialité et respect. La qualité du traitement des formulaires dira beaucoup du sérieux réel du mouvement.

**Recevoir. Classer. Répondre. Suivre. Protéger.**
