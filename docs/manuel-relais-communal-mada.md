# Manuel du Relais Communal MADA

## Mouvement pour l'Avenir, le Développement et l'Autodétermination

**Version :** 0.1 - Organisation territoriale  
**Statut :** Document de formation interne  
**Usage :** relais communaux, coordinateurs territoriaux, bénévoles terrain, préparation CTM 2028.

---

## 1. Rôle du relais communal

Le relais communal MADA est le point de contact local du mouvement dans une commune ou un bassin de vie.

Son rôle n'est pas de remplacer les élus, les associations, les services publics ou les institutions. Son rôle est d'écouter, comprendre, documenter, orienter et faire remonter les réalités du terrain vers l'organisation MADA.

Le relais communal doit permettre à MADA d'être présent dans la Martinique réelle : quartiers, bourgs, mornes, campagnes, littoraux, zones économiques, familles, jeunes, aînés, agriculteurs, pêcheurs, entrepreneurs, associations et citoyens isolés.

---

## 2. Mission principale

Le relais communal poursuit cinq missions :

1. **Écouter** les habitants avec respect.
2. **Identifier** les urgences locales.
3. **Documenter** les problèmes et les propositions.
4. **Mobiliser** adhérents, bénévoles et citoyens.
5. **Rendre compte** à la coordination territoriale MADA.

Le relais communal doit incarner une politique de proximité : sérieuse, calme, utile et responsable.

---

## 3. Ce que le relais communal peut faire

Un relais communal peut :

- présenter MADA et ses objectifs ;
- orienter vers les formulaires officiels du site ;
- organiser une réunion citoyenne locale ;
- recueillir des signalements ;
- identifier les besoins prioritaires ;
- rencontrer des associations, entrepreneurs, agriculteurs, commerçants ou acteurs locaux ;
- aider à construire le portrait de sa commune ;
- mobiliser des bénévoles ;
- transmettre des informations vérifiées à l'équipe MADA.

---

## 4. Ce que le relais communal ne doit pas faire

Un relais communal ne doit pas :

- promettre une décision au nom de MADA sans validation ;
- parler comme un élu s'il ne l'est pas ;
- collecter des données sensibles hors cadre officiel ;
- publier des accusations non vérifiées ;
- engager financièrement le mouvement ;
- organiser une action risquée sans validation ;
- se substituer aux services publics ;
- utiliser MADA pour régler des conflits personnels.

La crédibilité du mouvement dépend de la discipline et de la prudence de chaque relais.

---

## 5. Posture attendue

Le relais communal doit être :

- respectueux ;
- ponctuel ;
- à l'écoute ;
- discret sur les données personnelles ;
- clair dans ses explications ;
- ferme sur les valeurs ;
- capable de reconnaître ce qu'il ne sait pas ;
- fidèle à la parole officielle MADA.

Phrase repère :

**Je suis là pour écouter, comprendre, faire remonter et construire avec vous.**

---

## 6. Présenter MADA en deux minutes

Formulation recommandée :

**MADA est un mouvement politique martiniquais fondé en 2026 pour préparer l'avenir du territoire. Notre objectif est de construire une Martinique plus productive, plus responsable, plus transparente et plus autonome dans ses choix. Nous voulons écouter chaque commune, documenter les problèmes réels, proposer des solutions financées et rendre compte aux citoyens. Notre vision est simple : construire la Martinique de demain.**

---

## 7. Méthode d'écoute locale

Lorsqu'un habitant exprime un problème, le relais doit chercher à comprendre :

- quel est le problème exact ;
- depuis quand il existe ;
- qui est concerné ;
- qui est responsable aujourd'hui ;
- quelles démarches ont déjà été faites ;
- quelles conséquences concrètes il produit ;
- quelle solution le citoyen propose ;
- quelles preuves ou documents existent.

Le relais ne doit pas transformer une émotion en promesse. Il doit transformer une parole citoyenne en information utile.

---

## 8. Fiche de remontée communale

Chaque remontée importante doit être structurée ainsi :

| Champ | Contenu attendu |
| --- | --- |
| Commune | Nom de la commune |
| Quartier ou secteur | Si connu |
| Sujet | Eau, route, sécurité, logement, santé, jeunesse, agriculture, etc. |
| Description | Faits observés |
| Personnes concernées | Habitants, familles, entreprises, associations |
| Urgence | Faible, moyenne, forte |
| Responsable présumé | État, CTM, commune, EPCI, autre |
| Pièces utiles | Photos, liens, documents publics |
| Proposition citoyenne | Idée ou demande exprimée |
| Suivi MADA | À analyser, à orienter, à intégrer au programme |

---

## 9. Organisation d'une réunion locale

## 9.1 Avant la réunion

Préparer :

- objectif de la rencontre ;
- lieu accessible ;
- horaire adapté ;
- invitation claire ;
- ordre du jour court ;
- liste des personnes à inviter ;
- support de présentation MADA ;
- fiche de remontée des besoins.

## 9.2 Pendant la réunion

Le relais doit :

- accueillir avec respect ;
- rappeler l'objectif ;
- laisser parler les habitants ;
- éviter les débats personnels ;
- noter les faits ;
- distinguer les urgences des opinions ;
- conclure avec les prochaines étapes.

## 9.3 Après la réunion

Dans les 72 heures, le relais doit produire :

- un compte rendu court ;
- les sujets prioritaires ;
- les demandes à transmettre ;
- les contacts utiles ;
- les actions de suivi proposées.

---

## 10. Relations avec les acteurs locaux

Le relais communal peut rencontrer :

- associations ;
- commerçants ;
- agriculteurs ;
- pêcheurs ;
- enseignants ;
- clubs sportifs ;
- professionnels de santé ;
- entrepreneurs ;
- jeunes ;
- aînés ;
- familles ;
- acteurs culturels.

Objectif : comprendre les réalités de la commune, pas récupérer artificiellement leur parole.

---

## 11. Neutralité et respect démocratique

MADA peut être ferme politiquement sans manquer de respect.

Le relais communal doit respecter :

- les élus en place ;
- les agents publics ;
- les associations ;
- les citoyens d'autres sensibilités ;
- les personnes qui refusent de rejoindre MADA.

Le mouvement doit convaincre par le sérieux, pas par la pression.

---

## 12. Données personnelles

Le relais ne doit collecter que les informations nécessaires et orienter autant que possible vers les formulaires officiels du site MADA.

Il doit éviter de conserver localement :

- pièces d'identité ;
- données de santé ;
- informations judiciaires ;
- données concernant des mineurs ;
- documents privés sensibles.

En cas de sujet sensible, il faut prévenir la coordination avant toute diffusion.

---

## 13. Communication locale

Le relais peut relayer les contenus officiels MADA, mais ne doit pas créer de position politique nouvelle sans validation.

Avant publication locale, vérifier :

- ton digne ;
- absence d'accusation non prouvée ;
- image adaptée ;
- orthographe correcte ;
- cohérence avec la charte éditoriale ;
- respect des personnes.

---

## 14. Priorités à observer dans chaque commune

Le relais doit suivre régulièrement :

- eau ;
- routes ;
- transports ;
- logement ;
- santé ;
- sécurité ;
- jeunesse ;
- écoles ;
- sport ;
- culture ;
- agriculture ;
- commerces ;
- emploi ;
- environnement ;
- déchets ;
- littoral ;
- personnes isolées ;
- vie chère.

---

## 15. Indicateurs communaux MADA

Chaque relais doit aider à suivre :

- nombre de réunions locales ;
- nombre de demandes citoyennes reçues ;
- nombre de bénévoles identifiés ;
- nombre d'adhérents locaux ;
- sujets les plus signalés ;
- actions menées ;
- réponses apportées ;
- propositions intégrées au programme.

---

## 16. Relation avec la coordination territoriale

Le relais communal dépend d'une coordination territoriale. Il doit transmettre régulièrement :

- compte rendu mensuel ;
- urgences locales ;
- événements à venir ;
- besoins logistiques ;
- propositions citoyennes ;
- risques ou tensions ;
- demandes de validation.

La coordination doit accompagner le relais, pas le laisser seul.

---

## 17. Kit minimal du relais communal

Chaque relais doit disposer de :

- présentation courte de MADA ;
- lien vers le site officiel ;
- formulaire adhésion ;
- formulaire bénévolat ;
- formulaire relais communal ;
- fiche de remontée locale ;
- charte éditoriale ;
- charte graphique simplifiée ;
- contacts internes utiles.

---

## 18. Serment du relais communal

**Je m'engage à servir ma commune avec respect, vérité et responsabilité.**

**Je m'engage à écouter les habitants sans les mépriser, à faire remonter les réalités sans les déformer et à représenter MADA avec dignité.**

**Je m'engage à ne pas promettre ce que je ne peux pas garantir, à protéger les données des citoyens et à travailler pour l'intérêt de la Martinique avant toute ambition personnelle.**

---

# Conclusion

Le relais communal est l'une des clés de la réussite MADA. Sans présence locale, le mouvement resterait une idée. Avec des relais sérieux, formés et responsables, MADA peut devenir une force enracinée dans chaque commune.

**Une Martinique forte commence par des communes écoutées.**
