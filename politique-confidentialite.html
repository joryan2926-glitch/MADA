Données personnelles

Politique de confidentialité.

Cette page explique comment MADA collecte et utilise les données transmises par les formulaires du site.

Données collectées

Nom, email, téléphone, commune, message, type d'engagement, contribution programme ou intention de don selon le formulaire utilisé.

Finalités

Répondre aux demandes, gérer les adhésions, organiser le bénévolat, diffuser la newsletter, préparer les relais communaux et administrer les actualités.

Base de traitement

Les données sont transmises volontairement par l'utilisateur avec consentement explicite via les cases prévues sur les formulaires.

Droits

Vous pouvez demander l'accès, la rectification ou la suppression de vos données en écrivant à contact@mada-martinique.fr.

Conservation

Une base militante responsable.

Les données sont conservées uniquement pour les besoins de contact, d'information, d'organisation militante et de préparation programmatique. Elles ne doivent pas être revendues ni transmises à des tiers non autorisés.
